# Knowledge Management 测试用例库 (Test Case Repository)

本文件定义了系统的核心验收测试用例，涵盖 UI、业务逻辑及集成稳定性。

## 1. 核心业务流程 (L1 Cases)

### TC-101: 页面创建与插件拦截验证
*   **前置条件**：已启用“自动标签插件”。
*   **测试步骤**：
    1. 点击“新建页面”。
    2. 输入标题“AI 学习笔记”。
    3. 在正文中输入“这是一篇关于 AI 的研究”。
    4. 点击保存。
*   **预期结果**：页面保存成功后，正文末尾应自动出现 `#AI` 标签（证明插件 `preProcess` 拦截成功）。

### TC-102: 混合检索精准度验证
*   **前置条件**：知识库包含“苹果公司”和“红富士苹果”两篇文档。
*   **测试步骤**：
    1. 在搜索框输入“科技巨头”。
*   **预期结果**：排在第一位的应是“苹果公司”（证明向量检索成功匹配语义，而非仅仅匹配关键词）。

## 2. 界面与交互 (L2 UI Cases)

### TC-201: 跨端自适应布局切换
*   **测试环境**：iPad Pro (支持分屏)。
*   **测试步骤**：
    1. 全屏开启 Knowledge Management（应显示三栏布局）。
    2. 拖动分屏边缘，将应用调整为 1/3 窄屏模式。
*   **预期结果**：布局自动切换为 TabView 底栏模式，当前选中的页面 ID 保持一致。

### 2.2 集成测试 (Integration Tests) - P1
*   **TC-L2-001: RAG 管线链路测试**: 验证从 PDF 导入到向量召回的完整链路。
*   **TC-L2-005: 插件动态限流测试**: 模拟插件 > 100Hz 调用，验证系统自动执行 Throttling 降级。

## 3. 系统测试 (System Tests) - P0/P1

### 3.1 性能与稳定性
*   **TC-L3-001: 5万级文档检索延迟**: 验证混合检索首字弹出 < 800ms。
*   **TC-L3-008: 多节点最终一致性压测**: 模拟 3 节点同时修改同一 UUID 页面，验证 LWW 算法是否成功收敛。

### 3.2 安全与隐私
*   **TC-L3-009: 金库生物识别锁定测试**: 开启锁定后，验证非法尝试（无 FaceID）是否能阻断数据库访问。
*   **TC-L3-010: 插件越权拦截测试**: 模拟未声明网络权限的插件尝试发起 HTTP 请求，验证沙盒阻断有效性。

### TC-301: 插件安全模式管控
*   **测试步骤**：
    1. 开启“安全模式”。
    2. 尝试从本地加载一个未签名的插件包。
*   **预期结果**：系统弹出安全警告，并拦截加载行为。
